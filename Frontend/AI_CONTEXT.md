# Frontend context

This is the Next.js 16 (App Router) + React 19 + TypeScript browser application, styled with HeroUI v3 on Tailwind CSS 4 with Tabler icons, within the parent EduHub repository. Follow the workspace [context](../AI_CONTEXT.md) and [workflow](../AGENTS.md).

Routes live in `src/app/`: `(auth)` holds `/login` and `/register` (no site header/footer), `(site)` holds `/home`, the informational pages, `/courses/[id]`, and `/courses/create`; `/` and unknown URLs redirect. Pages that read the session or theme are client components. `src/api/axios.config.ts` builds requests to `${NEXT_PUBLIC_API_URL}/api` (default `http://localhost:8000/api`); `src/api/courses.api.ts` contains course calls. Auth is Better Auth: server config in `src/lib/auth-options.ts` (instance in `src/lib/auth.ts`, handler at `/api/auth/*`, tables migrated into the Postgres `auth` schema on server start by `src/instrumentation.ts`), client in `src/lib/auth-client.ts` (`authClient.useSession()` for UI state). The session is an HttpOnly cookie; API calls carry a short-lived JWT from `get-session`'s `set-auth-jwt` header, cached by `src/utils/tokenCache.ts`. The `role` field is set at sign-up and locked by a database hook; do not log tokens or weaken that hook. Course creation can send JSON or multipart form data with images.

Use existing npm scripts and read [TESTING.md](TESTING.md) for commands and browser evidence. There is no checked-in browser-E2E configuration. `node_modules/`, `dist/`, and `.tmp-tests/` are generated.
