# Backend agent notes

Apply the parent [workflow](../AGENTS.md) and [testing rules](../TESTING.md). Keep routes, schemas, auth dependencies, models, Alembic migrations and the frontend contract (`Frontend/src/api/`, `Frontend/src/utils/types/`) consistent. Keep course creation atomic (files are written only after validation and removed if the database write fails), test allowed and denied role/ownership paths, and add a new Alembic migration for every schema change (`alembic check` must pass). Do not log JWTs, credentials, upload contents or personal data. Review `app/config.py`, `app/main.py`, Compose and the entrypoint carefully: they control the database, CORS, trusted hosts, security headers, migrations and production startup.
